# Spec: делаем clamp-size находимым и подключаемым ИИ-агентами

Цель: агент, решая задачу вида "сделай фонт/отступ адаптивным через clamp",
сам находит `clamp-size`, ставит его и использует — без участия человека.

Порядок фаз важен: фаза 0 — блокер для всего остального. Агент, который
один раз получил битый вывод, второй раз пакет не порекомендует.

---

## Фаза 0 — Починить корректность (блокер)

Без этого остальное вредно: чем выше находимость, тем больше людей словят баг.

- [ ] `_clamp.scss:29-31` — `px-to-rem()` не отбрасывает единицу входа: при
      `size(16px, 24px, 'sm', 'lg')` (ровно то, что показывает README) на выходе
      `clamp(1pxrem, 0.3077pxrem + 1.9231pxvw, 1.5pxrem)` — невалидный CSS.
      Работает только unitless-вход. Приоритет #1: это ломается на каждом
      примере из README. Исправить `px-to-rem()`, чтобы отбрасывал единицу
      (`math.div($px, $px * 0 + 1)`), либо `@error` на входе с единицей —
      и в любом случае поправить README, если решено требовать unitless.
- [ ] `_clamp.scss:65-74` — тернарный `if(cond, a, b)` — устаревший синтаксис
      в dart-sass, при каждой компиляции сыплет `DEPRECATION WARNING
      [if-function]`. Агент/CI видит стену варнингов перед результатом;
      синтаксис в будущем станет hard error. Переписать на `@if/@else`.
- [ ] `_clamp.scss:85-86` — `dynamic-size()` вызывает публичный `size()` вместо
      `px-to-rem()` напрямую. Циклическая зависимость, ломается при рефакторинге `size()`.
- [ ] `README.md:27` — `@forward 'clamp-size';` не работает (нет корневого
      `_index.scss`), и `@forward` — не тот глагол для примера потребления
      пакета. Добавить корневой `_index.scss`, форвардящий `src/_clamp.scss`,
      и заменить пример на `@use 'clamp-size' as clamp;`.
- [ ] `_clamp.scss:68,73` — несуществующий ключ брейкпоинта (`'xxl'`) даёт
      `null` и глухую ошибку деления на ноль. Добавить `@error` с понятным текстом.

Проверено компиляцией через dart-sass — не полагаться на код-ревью без запуска.
`_clamp.scss:77-82` (инверсия через `* -1` при `$min-size > $max-size`) —
**не баг**: `calc(clamp(...) * -1)` корректно даёт положительный убывающий
размер, стандартный приём для clamp() (требует min ≤ max). Не трогать.

Источник: `.mimocode/plans/1782680454986-kind-meadow.md` (код-ревью, частично устарел — см. выше).

поддерживается и не сломан: тесты, CI, чистота репозитория.

- [ ] `scripts` в `package.json`: хотя бы `test`, желательно `lint`

## Фаза 3 — Формат, читаемый агентом

Отдельно от README для людей: агент, обходящий репозиторий или тянущий
`llms.txt`, должен получить API одним блоком, без прозы.

- [ ] `AGENTS.md` (или `llms.txt`) в корне: сигнатуры функций, параметры,
      2-3 примера на функцию, без маркетинга. Формат — таблица/список, не
      абзацы.
- [ ] Все примеры в README — самодостаточные блоки кода, которые можно
      скопировать и вставить без правок (уже почти так, проверить после
      фазы 1, когда изменятся пути импорта).
- [ ] Явное сравнение "почему не написать clamp() руками" — агенты уже
      умеют генерировать raw CSS clamp(), пакет должен продавать конкретную
      разницу (брейкпоинты по ключу, авто px→rem, инверсия направления, cqi).
